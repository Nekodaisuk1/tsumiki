# Experiment 008: Member solid collisions

Date: 2026-11-19

## Purpose

雄材・雌材の配置確定時に、描画上の木材実体の貫通を拒否する。節点IDの一致や中心線の交差だけでは判定しない。寸法は保存設計の無次元仮定を用いる。

## Method

- Three.js公式addon `OBB` の `intersectsOBB` を利用する。新規依存は追加しない。
- 雄材は本体と両端の角棒、雌材は角穴を除いた上下の帯と穴間・端のブロックへ分解する。現在の直方体・角穴の形状に対して、穴を外接箱で塞がない実体表現になる。
- 材の長軸・roll・重ね段・表裏に従って各ブロックを配置する。世界座標の外接箱で候補を絞った後、回転付きの箱を判定する。
- 接触面の数値誤差を許すため、各判定箱を各面から無次元 `5e-9` 内側へ縮める。世界座標の候補判定は `1e-8` を許容する。この付近の微小な貫入は判別対象外。
- 接続済みの部材ペアも除外しない。穴を正常に通る角棒は許容し、角棒を45度ねじって穴壁へ食い込ませた配置は拒否する。
- 共通の設計検証に組み込むため、編集確定・保存・読込・履歴復元に適用される。エラーには干渉した2部材のIDを含める。
- 雄材追加のプレビューも候補設計を検証し、干渉する場合は確定ボタンを無効化する。

## Regression fixtures

以前の正常系に含まれていた、同じ端点から伸ばして角棒同士が重なる雄材追加を雌材の外段追加に変更。同じ段の横板と交差する積層板は空いている2段目へ変更した。
v1移行で既定roll・layerが実体の衝突を生む旧データは拒否する。衝突のない雄材のみの旧データで移行と丸材の取付先維持を別途検証する。読込時の自動移動・自動削除は行わない。

## Scope

配置された雄材・雌材の静的な体積干渉に限定する。丸材の一般干渉、ロープの太さ・接触、ドラッグ経路上の衝突、変形後の衝突、衝突応答、実物の組立手順の成立性は未対応。既存の丸材の段占有検証は継続する。
干渉がないことは、接合や荷重伝達が成立することを意味しない。接合の垂直条件・段・穴の占有・ロープ予約領域は既存の別検証を用いる。

## Verification

- 単体・回帰テスト59件成功。雄材同士、雌材同士、雄雌の斜め交差、凸部同士、面接触、微小貫入、回転した非干渉材、正常差し込み、角棒のねじれを含む。
- 専用ブラウザテスト2件成功。干渉する移動・読込の拒否と設計保持、差し込みプレビューの拒否と正常配置を確認。

- 型検査・本番ビルド成功（既存のバンドルサイズ警告あり）。全体E2Eは別途変更中のタブUIで非表示になった「応答の表示」を旧テストが操作しタイムアウトしたため中断。全体E2E成功とはしない。専用テストは独立ポート5187で実行した。

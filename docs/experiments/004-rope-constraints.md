# 004: Rope constraints

## Status
In progress

## Objective
1.2 m刻みのロープによる張力と形状固定を再現する。

## Routing and winding
[製品仕様](../product.md#rope-routing)の A → C → B → D を用いる。AD・BCが雄材、AB・CDが雌材。両対角線と雄材BCに沿う経路を持ち、突出部への固定・掛け回しと雄材ADの回転による巻き取りを扱う。

ロープが関わる全部材への内向きの締め付けが再現対象。各接触点の前後の張力方向から力を求め、部材・接合へ伝達する。摩擦を導入する場合は区間ごとの張力差を扱う。

寸法値は保留。巻き取り部材は雄材AD。回転軸、端の固定・保持方法、交差部の接触は未確定。回転と巻き取り長さの関係は接触形状に応じて定義する。

## Updated joint assumption
接合は基本直交で、遊びによる微小な動きがある。ロープは歪みの是正と締め付けによる構造強度の確保に用いる。自由関節の大変形を主対象にしない。補強の定量評価は未実施。

## Inputs and dependencies
ロープ長、取付点、取り回し、有効長、初期張力・伸び・摩擦の条件。

## Acceptance criteria
ロープのたるみと張りを区別する。採用する張力専用モデルでは圧縮力を発生させない。固定の成立条件を示す。

## Implementation
探索用の共通プロトタイプを src/model.ts・src/main.ts に実装した。実物の巻き取り・接触モデルは未実装。規格が未確定の値は無次元パラメータとして扱う。

## Verification plan
単純な張力の釣り合い、経路の連続性、巻き取り量と張力の関係、部材へ伝わる力を確認する。ロープ付き構造の角度・変位と締め付け方向を実物と比較する。

## Results
[Prototype 01](../prototype.md)で、無次元の点接触・弾性ロープモデルを実装・検証した。実物の巻き取り機構は未実装。初期の自由関節モデルは実物の接合条件と異なるため比較用に限定した。既定は90°基本配置でロープ力を表示する。遊び・接触反力・補強の定量化は未実装。

3D解析では、張力ひずみを巻き取り後の張力として扱い、掛け点C・Bの摩擦を「滑る」「滑らない」の両極端で比較できる。補強効果は掛け点の滑りに強く依存する（[Prototype 05](../joint-clearance.md)）。

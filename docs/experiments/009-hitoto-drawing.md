# Experiment 009: Hitoto drawing geometry

Date: 2026-11-20

## Source and scope

ユーザー提供の `hitoto_zumen/hitoto_buzai_zumen.pdf`（77ページ）をテキスト抽出・画像描画・ベクター図形の位置で照合した。
SHA-256: `4bc21c4e7c5c46ada086597100b9fb0958baad0be19c2227855c88b110a44e65`。
PDF内の注記は製品の寸法資料として扱い、作業指示とは解釈していない。

既存の雄材・雌材・丸材を対象とする。天板・座面・アリ・根太・板幅210mmの板オス・角マン等の新しい部材種の追加はこの変更には含めない。

## Catalog and coordinates

- 形状座標1単位=1000mm。雄材の始終点は本体の肩、雌材の始終点は最端穴の中心を表す。雄材全長と雌材全長を節点間距離へそのまま入れない。
- 雄材300〜3600の15規格、雌材150〜3600の角端・丸端32規格、2400の密穴版2規格を登録。
- p22–41の図形は140.25mmピッチ。ベクターの円中心とレンダリングを照合し、描かれた穴配置を採用した。2026-11-20、実際の穴数は図形どおりで正しいとユーザー確認済み。表題の「穴数」は端から半分までを数えた表記の可能性がある、との説明を受けた。表題を全長の総穴数とは解釈せず、図面の不整合とは扱わない。表題の命名規則自体は推定であり、モデルの総穴数は図形を根拠とする。
- p42–45, p48–55, p75–77は280.5mmピッチ。p46–47の2400密穴版17穴は、9穴版とは別カタログIDとする。
- 旧データの仮定寸法を自動的に縮尺変更しない。v5は従来の角穴・寸法を保持し、図面規格はv6として保存する。
- 図面部材の長さと穴数は固定。規格外の節点移動・伸縮・種類変更は拒否する。姿勢と重ね段は引き続き編集可能。

## Assumptions and limitations

1. 凸部の角丸半径は不明。UIで調整できるR6.3mmを仮値とした。雌材の「トリマー6.3R」注記を凸部の確定寸法とは解釈していない。30mm角の鋭い角の対角は約42.43mmなので、φ39穴へ無条件に通さない。
2. 雌材の6.3R面取りの加工範囲・断面詳細は未確定のため未再現。雄材の肩・先端の面取りも未再現。
3. 丸マンの穴径は共通穴規格φ39mmとして扱う。p19自体には穴径の寸法線はない。
4. 凸部165mm=板厚5.5枚分。従来の組立4段（120mm）の制約は維持し、最後の30mmをロープ領域として接触点を肩から150mmへ移す。間の15mmは追加の段として利用しない。積層数を図面だけから増やさない。
5. 表示・干渉判定は同じ円弧の多角形近似を使う（48分割の円、φ39で最大弦誤差約0.042mm）。旧モデルの「接続した凸部を干渉判定から除外する」扱いを図面モデルには適用しない。
6. 材料・断面剛性・荷重・時間は従来の仮定値で、実物の力や耐力に校正していない。形状の実寸化だけで解析結果をNや秒へ変更しない。
7. 旧角穴のクリアランス接触則を丸穴に流用しない。図面モデルは剛接合の参考比較のみとし、クリアランス接触を指定した解析は明示的に拒否する。丸穴と角丸凸部の接触・摩擦モデルは別途必要。
8. 丸材・ロープの一般衝突および組立経路の連続衝突は今回の対象外。

## Verification

寸法・穴位置・丸い開口・半円端・角丸凸部・干渉・全49カタログの保存復元・旧形式保持を自動検証する。

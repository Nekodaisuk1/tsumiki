# 006: Rectangle shaping

## Status
In progress

## Objective
向かい合う雄材2本・雌材2本の枠を、2本の対角線と1本の雄材を通るロープの巻き取りで長方形に整形・固定する実物の挙動を再現する。

## Physical mechanism
[製品仕様](../product.md#rope-routing)の A → C → B → D の経路を使用する。巻き取りでは雄材ADを回転させる。004の接触・張力・巻き取りモデルに依存する。

固定辺長の平行四辺形では対角線長の和は長方形で最大となる。単なる経路長の最小化では説明できないため、突出部・回転軸・立体配置・摩擦等と実物の挙動の対応を検証する。長方形に座標を強制変更する処理を、物理モデルの検証の代用にしない。

## Updated joint assumption
接合は基本直交で、遊びによる微小な動きがある。ロープは歪みの是正と締め付けによる構造強度の確保に用いる。自由関節の大変形を主対象にしない。補強の定量評価は未実施。

## Inputs and dependencies
対象の四角形、部材長、接合自由度、干渉、ロープ条件。

## Acceptance criteria
ロープ経路と巻き取り操作を再現する。長方形へ整う機構を説明・検証できる。整形可能な例を処理し、不可能な例では理由を示す。

## Implementation
共通プロトタイプで長方形との比較と緩和計算を実装した。物理的な長方形化は未達成。実装は src/model.ts・src/main.ts にあり、実物の機構確認後にモデルを更新する。

## Verification plan
整形前後の辺長、角度、接合、干渉、ロープ条件を確認する。

## Results
[Prototype 01](../prototype.md)で、無次元の点接触・弾性ロープモデルを実装・検証した。実物の巻き取り機構は未実装。初期の自由関節モデルは実物の接合条件と異なるため比較用に限定した。既定は90°基本配置でロープ力を表示する。遊び・接触反力・補強の定量化は未実装。

## Integration notes

## Next steps

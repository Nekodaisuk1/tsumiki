# 002: Joint behavior

## Status
In progress

## Objective
穴と角棒の接合可否、回転・移動の自由度を再現する。

## Confirmed behavior
雄材は雌材にほぼ垂直に差し込まれる。遊びはあるが、大きく自由回転する関節ではない。遊びの量・方向は未確定で、寸法値の決定は保留。

接合の直交性・隙間内の小さな変位・接触後の反力を分けて扱う。枠のせん断変形とADの巻き取り操作の回転を混同しない。

## Inputs and dependencies
001の部材形状、接合規格、隙間・摩擦・抜け止めの条件。

## Acceptance criteria
適合・不適合な組み合わせを判別する。許容される微小な運動と拘束される運動を再現する。自由関節のような大きな角度変化を許さない。

## Implementation
[Prototype 05](../joint-clearance.md)で、穴と角棒の隙間・接触（摩擦なし）を3Dフレーム解析に組み込んだ。板の表裏2面の並進隙間、角穴内のねじりの隙間、シャフト方向の接触剛性を持つ。隙間は形状の無次元仮定から計算する。剛接合近似は比較用に残す。

## Verification plan
最小の2部材接合で実物または規格と比較する。

## Results
遊びのある枠は、ロープなしでは隙間の範囲で大きく傾いてから接触し、その後は半剛接合の剛性になる。巻き取ったロープが掛け点で滑らなければ全接合が着座し、変位はロープなしの約1/240になる。掛け点で滑るロープはほとんど効かない。詳細は[Prototype 05](../joint-clearance.md)。

接合部の摩擦、実物の隙間・接触剛性、実物との比較は未実施。

## Integration notes
未判定。採用するモデルの仮定、適用範囲、既知の制約を記録する。

## Next steps
実物で、掛け点でのロープの滑り、穴と角棒の隙間、ロープなし・締めた後の枠の傾きを確認する。揺れの途中での接触の開閉を扱う非線形の時間積分を実装する。

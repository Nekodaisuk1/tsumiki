# 地面接触・摩擦による静止支持

実寸解析の初期条件を、節点固定から「固定なし・自重・水平床との摩擦接触」へ変更した。旧固定支持は比較用として選択でき、設計に保存されている固定フラグ自体は変更しない。部材同士の接合は既存の剛接合近似を維持する。

## 計算条件

- 水平床の高さは、配置済み木材の実形状の最下点。任意高さからの落下は扱わない。
- 実形状の床に接する点から、各材の長手方向の両端側の接点を抽出する。板全面の分布接触を端部支持で近似する。穴の空間は接点として作らない。
- 接点を近い端節点に剛なオフセットで結び、並進・回転から接点の変位を計算する。地面に回転拘束を直接与えない。モーメントは接触力と腕の長さから発生する。
- 垂直方向は押し込みにだけ反力が発生する片側ペナルティ接触（1e7 N/m）。浮き上がる接点の反力・摩擦はゼロ。
- 接線方向は弾性的な静止摩擦近似。合成接線反力の上限を μN とし、接触の開閉・摩擦剛性を反復更新する。既定 μ=0.5 は床材未確認の仮定値で、0〜2の範囲で変更可能。
- 微小な対角正則化0.01で剛体自由度を扱うが、最終残差は正則化を除いた真の力・モーメントの釣り合いで確認する。許容値は1e-5×max(1,等価節点外力の絶対値最大)。正則化を地面反力として出力しない。
- 変位/回転成分が0.05を超えた場合や300回で収束しない場合は静止解を出さない。滑り・転倒の可能性と、運動計算ではないことを表示する。

反力合計・接点数・摩擦係数を画面に表示し、接点座標・3軸反力・摩擦限界状態・残差を解析記録に保存する。3Dビューでは固定マーカーを外し、支持接点を緑、摩擦限界の接点を橙で表示する。

## 適用範囲

これは小変形・静止状態の強度/たわみの参考解析。転倒・滑走・落下後の時系列アニメーション、接合部の開放/破壊、部材同士の新たな接触は未実装。従来の相対値によるロープ加振比較の支持則は変更していない。自重は既存の梁区間の無欠損断面に基づくため、穴による軽量化・凸部や張り出し・丸材の重量は未反映。

摩擦則の参考：[Rapier公式のCoulomb frictionの説明](https://rapier.rs/docs/user_guides/javascript/collider_friction/)。今回は部材の曲げを計算する既存弾性梁ソルバを再利用し、新しい剛体ライブラリは導入していない。

## 検証

自重と垂直反力の釣り合い、保存された固定フラグに依存しないこと、反力非負、接線反力≤μN、摩擦内の横荷重、摩擦超過、摩擦ゼロ、上向き荷重、直立材の転倒、および端点の順序反転をテスト。従来の片持ち梁の解析解との一致も保持する。

検証結果：単体テスト全体157件通過後、内部穴で接続した複数部材の検証を追加し、地面接触6件が通過。ブラウザ44件のうち37件は初回通過、7件は並行テストによる記録ファイル競合が発生したため出力先を分離して再実行し全件通過。ビルド・lintも確認。既存の大きなバンドル警告は継続。

## 大きな頂点配列の修正

地面高さの計算で全頂点を `Math.min(...vertices)` に展開すると、JavaScriptの引数上限を超え `Maximum call stack size exceeded` が発生した。30万頂点を与える回帰テストで再現し、地面高さ・接点範囲・反復解の最大値をループまたはreduceで集計するよう修正。30万頂点の接点抽出を含む関連12テスト、ビルド、lintが通過した。

実寸解析の結果先頭に構造の総重量（kg、解析区間の概算）と対応する自重（N）を表示する。密度×断面積×全解析区間長で集計し、穴・凸部等の未反映範囲を併記。解析記録にも `totalMassKg` / `totalWeightN` を保存する。関連11テスト・ブラウザ2テスト・ビルド・lintで確認。

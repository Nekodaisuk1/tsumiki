# Prototype 04: Hole snapping and outer rope workflow

## Confirmed rules

- 雄材の凸部は、雌材の板厚5枚分。実寸は引き続き保留。
- 肩から0〜3段の4枚分を雌材・丸材に使用し、先端の4段目1枚分はロープ用に確保する。
- 雌材を追加するときは、既存の雌材・丸材を含む最外段の次に配置する。内側の空き段を勝手に埋めない。
- 初期枠は段0・段1へ詰めて配置する。以前の段0・段2という不要な空隙は廃止した。
- 雄材の追加は、雌材の穴への垂直な差し込みから行う。
- ロープは、対応枠と専用の巻き取り雄材を選択して張り、先端の最外側に掛ける。

## Male insertion workflow

1. 「図の穴を選ぶ」を押して緑色の穴をクリックする。または雌材と穴番号を一覧から選ぶ。
2. 長さ比と表側／裏側を選ぶ。追加方向と座標は、板の面法線と穴の位置から自動計算する。
3. 半透明のプレビューと、接続予定の雌材枚数を確認する。
4. 「雄材を差し込む」で確定する。座標を先に入力して後から位置を合わせる必要はない。

使用済みの穴は選択不可。既存の端部の雄材と、中間穴の保存済み接続を検査する。平行な雌材が重なっている場合は、該当する穴を通るシャフトを探索し、全ての接続を自動的に記録する。肩は重なった板の外面へ配置し、同じ板を雄材本体が貫くことを避ける。

シャフトが穴のない板面に当たる、面に垂直でない、板厚刻みを満たさない、4枚分を超えて先端のロープ領域を使う場合は拒否する。一般の本体同士の全衝突検査までは行わない。

## Structural connection

形式v4のconnections配列に、雄材ID・雌材ID・始点側/終点側・穴番号・段を保存する。表示上の穴に置くだけではない。

解析時は雌材の元の1枚板を設計データ上で保持したまま、接続した穴位置で梁を分割して剛性を組み立てる。接続端点は共有の6自由度で拘束する。雌材の積層位置、穴位置、雄材の肩位置の違いには剛なオフセットを使い、並進と回転・モーメントの伝達を扱う。分割要素の静的端内力は `m4[1]` 等で表示する。

質量は引き続き探索用の対角集中質量。偏心の完全な整合質量、接合の遊び・摩擦・接触応力、穴による断面欠損や破壊は未実装。

## Rope workflow

1. 「ロープを張る」を押す。
2. 図の面または一覧から、対向する雄材2本と雌材2本が構成する平面の四辺枠を選ぶ。
3. その枠の雄材から巻き取り用を選ぶ。他ロープで予約された材は選択不可。
4. 確定すると、選択した材をADとしてA→C→B→Dを構成する。同じ枠の既存ロープは二重追加せず更新する。

巻き取り雄材はそのロープ専用。他のロープの巻き取り材・反対側の掛け回し材としての共用も拒否する。巻き取り専用でない掛け回し材同士の共用は、現在は許容する。

接触点は各雄材の肩から外向きに板厚4.5枚分、すなわち先端用1枚分の中央。描画と解析で同じ接触点を使い、先端に作用するロープ力の偏心モーメントも剛性勾配に含める。実際の巻き付き半径・摩擦・結び・巻き取り動作は未モデル化。

## Reproducibility

保存形式は `tsumiki-design` v4、解析モデルは `frame3d-linear-v4`。穴接続を含めて保存・再計算する。v1・v2・v3は明示的に移行して読み込むが、ロープ用に予約した段に部材がある場合や、巻き取り材が重複する場合は移行を拒否し、勝手に削除・移動しない。既存ファイルの空隙は設計情報として保持し、初期枠の作り直しだけを詰めた配置にする。

## Verification

- 穴の貫通、左右凸部、板厚比、最外追加、ロープ予約領域、穴接続、板間の力の伝達、ロープ接触点・専用材を数理・形状テストで確認する。
- 中間穴に雄材を付け、両端固定の雌材の曲げ変位と雄材の軸伸びの理論解を比較する。
- ブラウザで実際の穴クリック、プレビュー、差し込み、構造解析、保存復元を確認する。
- 図の面クリック、巻き取り材選択、最外側への配置、二重追加防止を確認する。

## Operation
`npm ci` → `npm run dev` → 表示されたローカルURLを開く。標準ポートは5173。旧2D試作は `/rope.html`。

1. 仮の立体枠を回転・拡大して見る。幅・奥行・高さは実寸ではなく無次元の比率。
2. 節点選択でXYZと支持を編集する。節点・部材・丸材の追加、部材・節点の削除が可能。
3. ロープ経路A,C,B,Dを編集・追加・削除する。巻き取り雄材はA,Dの組から特定する。
4. 荷重点・方向・外力・床加速度・周波数・加振停止時刻等を設定して「3条件を再計算」。
5. ロープなし・たるみ・張力ありの静的変位と加振ピーク値を比較する。
6. 外力加振と床加振を再生し、時系列を比較する。加振停止後の自由応答も含む。
7. 設計を `.tsumiki.json` に保存。再読込すると同じ条件から再計算する。解析記録も別途JSON出力できる。

## Structural model

### Members and joints
1節点あたり並進3・回転3の6自由度、3Dの線形Euler–Bernoulli梁を使う。E・G・A・Iy・Iz・Jから軸伸縮・曲げ・ねじりの剛性を組み立てる。局所xは部材の始点から終点。基準ベクトルは原則全体Z、局所xとほぼ平行なら全体Yとし、その外積で局所y、続く外積で局所zを作る。現在は部材ごとのroll角で断面軸を回転できる。

接合は剛接合の近似。実物に遊びがあることは確認済みだが、その量・接触則はまだ計算していない。隙間・接触は[Prototype 05](joint-clearance.md)で追加した。単に共有節点を使っており、穴と角棒の適合・差し込み順序・複数部材の実際の接続可否は未検証。曲率を持つ部材の変形描画は未実装で、節点間を直線で表示する。

### Ropes
A→C→B→D全経路を1本の連続ロープとして扱い、摩擦なしで張力を一様とする。区間ごとに独立した筋交いとは扱わない。

基準長Lと経路長の一次変化ΔLに対して `T = max(0, EA * (prestrain + ΔL/L))`。たるみケースはprestrainの代わりに負のslackを使う。静的解析は張り・たるみのアクティブセット反復で解く。初期張力による節点力と枠の初期変位を計算し、荷重増分と区別する。

各面の経路と巻き取り雄材は記録するが、回転・巻き付き・摩擦・滑り・結び・保持そのものは未モデル化。初期張力は巻き取りの結果を仮入力したもの。ロープの実長規格1.2 mとの対応は寸法保留のため未対応。

一次の材料剛性モデルであり、張力・圧縮力による幾何剛性、P–Δ、座屈、大変形は含めない。連続ロープの理想経路では枠のせん断に対する一次の経路長変化が相殺される場合もある。締め付けによる接合剛性・摩擦の増加を未実装なので、実物の補強効果を十分に説明できるとは限らない。

### Static loads
並進の集中荷重、同じ軸まわりのモーメント、自重係数による鉛直荷重を扱う。梁の質量を端点へ半分ずつ集中させ、回転慣性は各半質量×部材長²/12の探索用近似。丸材・ロープの質量は含めない。静的比較値は、初期張力のみの平衡からの追加変位。表示形状と端内力は初期張力を含む全応答。

### Dynamics
自重・初期張力の静的平衡を求め、その時点の接線剛性を固定して、`M q̈ + C q̇ + K q = f(t)` をNewmark平均加速度法（β=1/4、γ=1/2）で積分する。

- 外力加振: 荷重点に正弦波の力・モーメントを加える。
- 床加振: 固定支持が一様に動く相対座標系で、方向成分に `−M r a_g(t)` を与える。変形・変位は床からの相対量。支持の滑り・浮き上がりは含まない。
- 加振停止時刻以降は入力ゼロ。全条件で同じtimeStep・波形・入力値を使う。
- 減衰は質量比例。係数は裸の梁剛性の対角値と質量の平均から決める参照周波数 `sqrt(mean(K_ii/M_i))` と相対減衰パラメータにより `C = 2 ζ ω_ref M` とする。ζを全モードの実測減衰比とは解釈しない。裸の枠の参照を全ロープ条件で共有する。
- 応答中にロープの張り・たるみが切り替わる可能性を検知した場合、表に `*` を付け、接線固定の近似が成立しない参考値として警告する。切替後の非線形応答を正しく解いたものではない。

## Validation
片持ち梁の曲げ・ねじり、支持反力と釣り合い、面外応答、拘束不足、引張専用条件、設計round tripと計算一致をテスト。時間積分は単自由度の調和外力の解析解と比較し、時間刻みを半分にすると誤差が減少することも確認する。実物の材料・接合・強度検証は未実施。

ブラウザでは3D編集・加振再生・設計入出力の結果一致・壊れたファイルの拒否・デスクトップとモバイルの表示・アクセシビリティ自動検査を確認する。

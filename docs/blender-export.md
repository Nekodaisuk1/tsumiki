# Blenderへの書き出し

上部の「↓ Blender（GLB）」で、図面規格の設計（v6）を実寸のGLBファイルとして保存できます。Blenderでは「ファイル → インポート → glTF 2.0 (.glb/.gltf)」から開きます。

- 1座標単位 = 1m。Blender側で軸の変換を行うため、手動の90度回転や1000倍の拡大は不要です。
- 雌材の貫通穴・端部形状、雄材の凸部、丸材、ロープの配置と色を含みます。
- 部材ID・規格名でグループ化します。雄材は胴体と両端凸部のメッシュを子として保持します。
- 確定済みの変形前形状を出力します。編集中のプレビュー、節点マーカー、選択枠、床、解析の色・変形曲線は含みません。
- ロープは表示用の直線区間・半径6mmです。実物の太さや巻き付きを再現するものではありません。
- メッシュ形式です。解析条件や編集履歴の保存・エディタへの再読込には、従来の「設計を保存」を併用してください。
- 寸法未確定の旧設計v5は、誤った実寸を渡さないため対象外です。

既存依存のThree.js GLTFExporterを遅延読込し、表示用と同じ形状生成関数を利用しています。追加パッケージはありません。

検証：ブラウザからGLBをダウンロードして形式・メッシュ・部材名を確認。実際のBlenderでインポートし、標準2400雌材が2400×105×30mmであること、9穴が貫通し穴間には木材があることを確認しました。

# Prototype 03: Patterned parts and editor

## Superseded workflow
現在の操作は[Prototype 04](hole-snap-and-rope.md)を参照する。初期の1枚分の隙間は廃止し、標準は0・1段へ詰めた。雄材は穴を選ぶ垂直スナップに変更し、中間穴も解析上接続する。以下は以前の試作記録。

## Confirmed geometry
雄材は横長の板の左右端に角棒が突き出す。雌材は等間隔の貫通穴を持つ。丸材は、連続構造で雄材の内側に生じる空隙を埋めるため、角棒にはめる。

実寸は保留。現在の板幅・板厚・角棒・穴は無次元の描画仮定として保存する。雌材の穴は同じ幅の角棒が通る角穴として試作しているが、実物の規格を確定したものではない。

## Everyday editing

1. 雄材／雌材を選び、節点と追加方向・長さ比を指定して「選択節点から部材を追加」。既存の終点に一致すればその節点を再利用する。
2. 部材・丸材・節点を3D図でクリックして選択。「選択を編集」で対応する設定へ移動する。
3. 「移動」をオンにし、XYZの矢印をドラッグする。移動刻みにスナップする。数値入力と±XYZボタンでも移動できる。
4. 2つの既存節点を接続するには、先に始点を選び「選択節点からクリックで接続」を押して終点を図でクリック。Escで解除する。
5. 「枠の構成 → 奥に1区画つなぐ」で、最奥の4節点の面を複製して連続する枠を追加する。既存面の節点は共有する。
6. 板の回転、雌材の重ね段、穴数を設定する。回転は描画と解析の断面軸の両方に反映する。
7. 雄材またはその端の節点を選んで「丸材を配置」。最も内側の空き段にはまる。丸材欄で取付先・左右・段を確認・変更できる。
8. 「元に戻す／やり直す」は設計全体を復元する。Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z、Ctrl+Yにも対応。テキスト入力中は入力欄の標準Undoを優先する。
9. 変更はブラウザに下書き保存する。再訪時は「下書きを復元」。専用ファイルでの保存・読込にも対応する。

「設計・無変形」と「解析結果」を切り替える。移動操作は無変形の設計に対して行い、拡大表示した変位を誤って設計座標に書き込まない。加振の再生時は解析結果へ切り替わる。

## Standard frame
雄材はX方向の横材、雌材は鉛直および奥行方向に配置。前後の2面にA→C→B→Dのロープを設ける。段0と段2に雌材が重なる描画例とし、段1に丸材を入れる例を確認できる。これは実物の寸法・積層順の決定ではない。

## Limitations
丸材をはめる位置・空き段の判定は行うが、その接触力や締め付けによる剛性増加は未解析。穴は立体形状に反映するが、梁の断面欠損・局所応力は自動計算しない。積層による偏心は梁中心線の解析に含まない。雌材の中間穴は表示されるが、中間穴を選んで接続し元の1枚板として解析する操作は未実装。一般の衝突・実物の組立可能性も未検証。

## Verification
貫通穴をレイ交差で検証し、塗装表現ではないことを確認する。左右の角棒の範囲、丸材の穴の軸、雄材への取付と空き段・重複拒否、区画接続、履歴、v1移行、専用形式のround tripをテストする。ブラウザでは追加・編集・再生・Undo/Redo・区画追加・丸材・下書き復元・エクスポート再読込を検証する。

## Verification results

- 数理・形式・形状・履歴テスト28件成功。貫通穴を通過するレイ、左右凸部、丸材の穴、空き段、連続区画、断面軸回転、v1移行を含む。
- E2Eテスト10件。図上の部材クリックと実際の矢印ドラッグ、刻み移動、追加、Undo/Redo、区画連結、丸材の重なり拒否、下書き復元、入出力一致、デスクトップ・モバイル、アクセシビリティ自動検査と旧2D回帰を含む。
- 型検査・本番ビルド・静的検査を実行。3Dライブラリを含むJSのサイズ警告が残る。

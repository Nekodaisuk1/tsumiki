## Objective
規格化された木材部材とロープから構造物を作成し、物理的な組み合わせ、運動、固定、荷重による変形を再現する。各部に作用する力とねじりを確認できるようにする。

## Materials

### Female member
長方形の板状の木材。雄材の差し込み部分を受け入れる貫通穴が等間隔に配置される。穴は塗装や印ではなく、差し込み部が通る開口として表現する。

未確定: 長さ・幅・厚さ、穴の形状・寸法・間隔・端部からの距離、木目方向、材質。

### Male member
横長の板材の左右、すなわち短辺側の両端に、差し込み部となる角棒が突き出す。標準配置は横向き。左右の凸部長は雌材の厚み5枚分で、そのうち先端1枚分はロープ用、4枚分を雌材・丸材に使用する。

未確定: 本体寸法、角棒の断面・長さ・向き、本体との一体性、接合部の遊びの範囲・接触特性と抜け止め。

### Ring member
雄材・雌材と同じ厚み・幅を持つドーナツ状の木材。中心穴の規格は雌材と共通。雄材の角棒にはめるスペーサーとして使い、連続構造で雄材の内側に生じる空隙を埋める。

未確定: 「幅」が径方向の肉厚を意味するか、内外径、中心穴の実規格、空隙量・積層順序・接触による力の伝達。役割はスペーサーとして確認済み。

### Rope
組み立てた木材にテンションをかけ、回転を止めて任意の角度・形状で固定する。長さの規格は1.2 m刻み。

取り回しと巻き取り操作は下記の Rope routing に記載する。未確定: 使用可能な長さの範囲、結び方の詳細、初期張力、伸び、摩擦、滑り、たるみ、巻き取り後の保持方法。
長さの規格と、結び・取り回し後の有効長は区別する。

## Joint behavior
雄材は雌材に基本的に垂直に差し込まれる。接合部には遊びがあるが、大きく自由回転する関節ではない。遊びの量・方向・接触剛性・摩擦は未確定。寸法値は引き続き保留する。

ロープの主な役割は、もともとほぼ直交する構造の歪みを是正し、内向きの締め付けによって構造強度を確保すること。自由にせん断変形する四辺形を大きく回して長方形にする前提は採用しない。具体的な剛性・耐力の改善量は解析・検証前に断定しない。

ADの巻き取り操作と、枠の接合角が大きく変わる運動は区別する。ADの回転軸・接合状態は別途確認する。

## Dimension policy
部材寸法の具体値はユーザーの指示により保留する。確定を求めず、記号・パラメータで仕様を整理する。

## Rope routing
対象は雄材2本と雌材2本がそれぞれ向かい合う辺をなす四辺形で、長方形に整形・固定する枠である。接合部の遊びや小さな歪みを是正する過程を対象とする。対象判定の詳細は実験で定義する。

四隅を周方向に A, B, C, D とし、AD・BCを雄材、AB・CDを雌材とする。

```text
A ---- female ---- B
|                |
male          male
|                |
D ---- female ---- C
```

1. Aで、雄材が雌材の穴から突き出た部分にロープの片端を固定する。
2. 対角のCまで延ばし、そこの突出部に掛ける。
3. 雄材BCに沿ってBまで延ばす。
4. Bから対角のDまで延ばす。Dは開始点Aと雄材ADを共有する。
5. 引く側の端を固定して雄材ADを回転させ、ウィンチのようにロープを巻き取って張力を与える。

経路は A → C → B → D。どの雄材・突出部を開始点に選んでも、同等の経路を表現する。

ユーザーの説明する実物の挙動: 対角線を経由するロープを締めると長方形に整い、固定される。また、ロープに関わるすべての部材に内向きの締め付け力が働く。

この観察・意図を再現対象とする。作用力の方向・大きさは、実際の接触位置、経路、摩擦、巻き取り、接合条件から計算して検証する。

### Historical modeling question
初期試作は接合を自由関節と仮定していたが、実物の基本直交の接合とは異なる。以下は旧仮定の比較結果であり、実物の補強効果の評価ではない。

「対角線を経由したロープを最短にすると長方形になる」という説明は、モデルの前提として固定しない。辺長一定の理想的な平行四辺形では、2本の対角線の長さの和は長方形で最大となるため、点状の四隅だけを通る張力ロープの単純な最短化とは一致しない。

実物との対応には、突出部への掛かり方、巻き取りによる接触・経路の変化、接合の回転軸や隙間、部材の立体配置を確認する。形状を強制的に長方形へ変更して物理的な再現と見なさない。

## Required behavior

- 4種類の材料を選び、配置・接続して構造物を作成できる。
- 穴と差し込み部の適合、部材同士の干渉、接合の自由度を扱う。
- 組み合わせた構造物が、実際の接合条件・荷重条件に沿って動く。
- ロープの張力による拘束と、形状・角度の固定を扱う。
- 各部の力、ねじりを表示する。具体的な表示量・位置・単位は解析仕様で確定する。
- 向かい合う雄材2本・雌材2本の枠を、上記のロープ経路と巻き取り操作により長方形に整形・固定する機能を設ける。
- 整形時も部材寸法、接合制約、干渉、ロープ長を満たす。整形不能な場合は理由を示す。

## Priority: three-dimensional reinforcement
主目的は荷重や揺れに耐える立体構造の作成・評価。ロープによる締め付けが、荷重下の変形、揺れ、接合部のがたつきにどう作用するかを比較する。2D枠の長方形化は主目的ではなく、局所的な機構確認に限定する。

次のプロトタイプは、3D表示と3Dの力学モデルを備える。カメラで立体的に表示するだけで解析を3D対応としない。同一の構造・支持・外力について、ロープなし／たるみ／張力ありを比較する。

まず静的荷重への応答を検証し、その後に質量・減衰・接合特性を含めて動的応答を検証する。補強による剛性変化と、耐力・破損限界、減衰効果は別々に評価し、張力があるだけで一律に強くなるとは仮定しない。

寸法は保留のため、初期段階の入力・結果は無次元の仮定に基づく相対比較に限定する。実物の耐荷重や耐震性能を数値として示すには、寸法・材料・接合特性の確定と検証が必要。

## Analysis scope
剛体としての運動・接合反力と、変形可能な木材としての曲げ・ねじり・応力を区別する。剛体の挙動が再現できただけで、応力や変形の妥当性を確認済みとしない。

解析対象の候補: 軸力、せん断力、曲げモーメント、ねじりモーメント、変位、接合反力、ロープ張力。ユーザーの必要性と検証可能性に基づき段階的に確定する。

重力、支持条件、外力、材料特性、接合特性、単位系を明示する。強度評価や破断予測は現時点で未確定。

## Prototype

[Prototype 04](hole-snap-and-rope.md): 初期の不要な空隙を除去。雄材は穴選択による垂直スナップと解析上の強制接続、雌材は最外側追加。ロープは枠と専用巻き取り材を選んで最外側に配置する。形式v4。

[Prototype 03: Patterned parts and editor](editor.md): 左右凸の雄材、雌材の貫通穴、雄材への丸材取付、重ね段と空き段、直接選択・移動・連続区画・操作履歴を追加。形式v2で形状・丸材取付先を保存する。形状は無次元の仮設定、一般の干渉判定と接触解析は未実装。

[Prototype 02: Structure Studio](prototype-3d.md): 3D設計・静的荷重・外力加振・床加振とロープ3条件の比較。[専用形式](design-format.md)で入力を保存・再現する。寸法は保留、遊び・摩擦・実物の強度は未評価。

[Prototype 01: Rope Lab](prototype.md)を作成。既定は90°の基本配置でロープの力を表示する。旧自由関節モデルは比較用として分離。接合の遊び・反力・歪み是正・補強効果は未実装。寸法は保留。

## Implementation strategy

1. 部材と接合をパラメータで表現し、形状・組み合わせを検証する。
2. 剛体と拘束による小規模な運動モデルで接合自由度とロープを検証する。
3. 梁・フレーム等による構造解析を検証し、曲げ・ねじり・変位を扱う。
4. 接合周辺の局所的な変形や応力が必要なら、詳細モデルの追加を検討する。
5. 検証したモデルを編集・表示機能に統合する。

技術選定は未実施。汎用剛体モデルのみ、全面的な詳細解析、段階的な剛体・構造解析の併用を比較し、実験の切り分けと検証容易性から併用を暫定方針とする。モデル間で形状・支持・荷重・接合条件の対応を保つ必要がある。

## Validation

「現実と同じ」の判定には、対象条件と許容誤差を定める。

- 幾何: 寸法・穴位置・接続可否・干渉を既知の例で確認する。
- 接合: 許される回転・移動・抜けを、実物または仕様と比較する。
- 解析: 単純な梁や釣り合い問題を理論値と比較する。
- ロープ: たるみ・張り・張力による固定を既知条件で確認する。
- 実物: 同じ組み立て・支持・荷重で、変位や角度等を測定して比較する。

許容誤差、対象荷重範囲、構造規模は未確定。検証前に定める。

## Open questions

- 部材規格と材質、接合の自由度・摩擦・隙間・抜け止め。
- ロープが掛け点（雄材の凸部C・B）で滑るか。補強効果がこれに強く依存することを解析で確認した。
- ロープ端の固定先と結び方の詳細、雄材ADの回転軸・巻き取り方向、保持方法、対角ロープの交差部の接触。
- 遊びの接触・締め付けが歪みと剛性・耐力に及ぼす作用。
- 3Dを優先する。実行プラットフォームと編集操作の詳細は未確定。
- 初回の立体構造、支持・床接触の条件、外力の作用点、加振の波形・振幅・周波数。揺れは人による外力加振と床・地面による支持点加振の両方を比較する。
- 静的解析・動的解析それぞれの必要範囲。
- 必要な精度、最大部材数、実物による検証方法。

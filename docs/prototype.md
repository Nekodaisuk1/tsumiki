# Prototype 01: Rope Lab

## Scope revision
主目的は立体構造の荷重・揺れへの抵抗と補強効果であり、2D枠の動きだけでは十分に評価できないことをユーザーと確認した。この試作はロープ経路と旧仮定の説明用に限定し、次の主対象を[007: Three-dimensional reinforcement](experiments/007-3d-reinforcement.md)へ移す。3D解析はまだ実装していない。

## Purpose
部材寸法を確定せず、ロープと四部材枠の機構について不足情報を発見する。実物に対して未検証の探索用プロトタイプ。

## Updated understanding
ユーザー確認: 雄材は雌材に基本的に垂直に差し込まれ、遊びはあるが大きく回転しない。ロープは主に歪みの是正と構造強度の確保に使われる。

既定を「基本直交」に変更した。90°を表示上固定し、ロープ経路と相対的な張力・接触点へのロープ力を確認する。これは遊びゼロを実物の仕様として確定したものではない。遊びの量、接触反力、変形、補強効果は未実装であり、動きの計算は無効化する。

初期の大きく回転する自由関節は「旧仮定の比較」モードとして残す。旧モデルの計算結果を実物の変形・強度の説明に使用しない。エクスポートには jointMode とモデルバージョン rope-routing-v2 を記録する。

## Operation
`npm ci`、`npm run dev` の順に実行し、表示されたローカルURLを開く。

1. 基本直交の枠で雌材と雄材の辺長比を変える。角度は90°で表示する。
2. ADの巻き取り量を変え、張力と接触点への合力を見る。
3. 必要なら「自由関節（旧仮定の比較）」に切り替え、角度と旧モデルの緩和計算を比較する。実物の接合とは異なる。
4. 「90°に配置して比較」で長方形と比較する。これは手動配置であり、物理的な整形ではない。
5. 実物との違いを観察メモに書き、実験条件とともにMarkdownで保存する。

角度・辺長比を手動変更すると、その形の経路長が基準長になる。巻き取り量を差し引いた値をロープの自然長とする。計算中は自然長を固定する。メモだけをブラウザに自動保存し、条件の復元は実装していない。エクスポートには再計算に必要な基準長・自然長・角度・辺長比・剛性・モデルバージョンを含む。

## Implemented model

- 雄材AD・BCは長さ1、雌材AB・CDは同一長の比率パラメータ。既定は90°配置。旧自由関節モードのみ、角度を自由度とする平面の剛体平行四辺形。
- ロープ経路はA → C → B → D。穴・突出部の描画は模式表示で、穴数・形状等の規格を意味しない。
- 接触点は点、摩擦なし、ロープ張力は一様。交差部での接触は扱わない。
- 巻き取りはADで行う操作の近似として自然長を減らす。ADの実際の回転・巻き付き形状・トルクは計算しない。
- ロープは張力だけを持つ線形弾性モデル。力・長さは無次元。
- ロープの接触点に働く合力を表示する。木材内部の軸力・応力や接合反力は表示しない。
- 動きはロープの弾性エネルギーを下げる1自由度の過減衰緩和。慣性・実時間・重力・外力・材の弾性は含まない。
- 25°〜155°は試作の計算範囲。端で停止することは、実物の安定・固定を意味しない。
- 丸材、任意の構造の編集、3D、強度・破断、ロープ規格長からの選択は未実装。1.2 m刻みの実長との対応には寸法が必要なため保留する。

## Historical free-joint findings
固定辺長の平行四辺形では、2本の対角線長の和は長方形で最大になる。本モデルでは張力を与えると、直角より小さい角度はさらに小さく、大きい角度はさらに大きくなる。厳密な90°は対称性で静止するが、微小なずれに対して復元しない。

したがって、現時点の点接触・経路長モデルだけでは、説明された実物の長方形化を再現できていない。これは実物の挙動を否定する結果ではなく、接触・接合・巻き取り等のモデル化に不足がある可能性を示す。

## Missing information

1. ADの回転軸: 材の長手軸か、接合部の軸か。それぞれの回転が構造にどう作用するか。
2. ロープの表裏・接触: A/C/B/Dの突出部にどちら側から掛け、何周し、どこで接触するか。
3. 引く側の端の固定先と、回転後の保持・逆転防止方法。
4. 接合は基本直交であることを確認済み。残る情報は遊びの量・方向、角棒と穴の接触・摩擦・抜け止め。
5. 立体配置: 交差したロープ同士や、ロープと材の面の接触。
6. 初期状態と操作: 手で枠を整える工程、巻き取り中に支える箇所等の有無。

部材寸法はユーザー指示により引き続き保留する。

## Verification results

- 数理テスト9件: 辺長保持、経路、長方形での経路長最大、無張力、合力・モーメント釣り合い、エネルギー勾配、緩和方向、対称性、無効入力・範囲制限を確認。
- TypeScriptの型検査と本番ビルドを実行。
- ローカルChromeでE2Eテスト4件: 基本直交での既定表示・操作制限と張力変更、旧自由関節の条件操作・緩和・矢印表示・リセット・比較、メモ永続化・Markdown内容、デスクトップ/モバイル表示・axeのWCAG A/AA自動検査を確認。
- 計算モデルの検証であり、実物の精度検証は未実施。

再実行コマンド: `npm test`、`npm run build`、`npm run lint`、`npm run test:e2e`。
